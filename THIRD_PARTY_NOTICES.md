## Demo prerequisites

- [TrueForge](https://github.com/truefoundry/trueforge) (MIT) provides the local agent runtime.
- [Flask](https://github.com/pallets/flask) (BSD-3-Clause) is the external demo target.
- [llama.cpp](https://github.com/ggml-org/llama.cpp) (MIT) served the local demonstration model. It is a separately installed executable.
- [Qwen2.5-3B-Instruct GGUF](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF) (Qwen license) supplied the separately downloaded Q4_K_M model weights.
- [Qwen3-4B GGUF](https://huggingface.co/Qwen/Qwen3-4B-GGUF) (Apache-2.0) supplied separately downloaded model weights for the multi-file evaluation.
- [Open Sans](https://www.opensans.com/) is embedded in the technical report. Digitized data copyright (c) 2010–2011, Google Corporation. [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).
